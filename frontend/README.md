
# Frontend Aeropro Companion (React + Vite PWA)

## Cómo ejecutar

```bash
cd frontend
npm install
npm run dev
```

La app se sirve en `http://localhost:5173`.

Incluye:
- Navegación inferior tipo app móvil.
- PWA (manifest + service worker).
- Pantallas de ejemplo: Hoy, Inhalaciones, Síntomas, Resumen, Perfil.
