
# Aeropro Respiratory Companion

Proyecto base con:

- Backend: FastAPI + SQLAlchemy + JWT (carpeta `backend/`)
- Frontend: React + Vite + PWA (carpeta `frontend/`)

## Estructura

- `backend/`: API para usuarios, perfiles, tratamientos, inhalaciones, síntomas, eventos y resumen básico.
- `frontend/`: App web responsiva tipo app nativa, lista para instalarse como PWA.
